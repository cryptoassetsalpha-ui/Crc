Use kaise karna hai

1. Entry add karo: match, party, type, side, amount, result.
2. Win = profit me count hoga. Loss = loss me count hoga. Pending = pending settlement me count hoga agar settled No hai.
3. Settlement ke liye type “Settlement” choose karke Receive/Pay side use kar sakte ho.
4. Data sirf phone/browser me save hota hai. Browser clear karoge to data delete ho sakta hai. Export CSV backup ke liye use karo.

Note: Ye tool sirf private accounting/record keeping ke liye hai; legal rules apne area ke hisaab se follow karo.
